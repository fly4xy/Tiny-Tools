# Tiny Tools

[English](README.md) | **Русский**

Аддон для Blender для риггинга и анимации (4.2 / 4.5 / 5.2 LTS): бэкап скелета и анимаций, Pose Master (текущая поза становится новой rest-позой без поломки мешей и анимаций), инструменты аниматора для ключей и поз, экспорт анимаций в FBX для Unreal Engine 5, симметризация, перенос и сглаживание весов.

- 🌐 Страница проекта: https://lis-carter.site/tiny-tools/
- 🐞 Сообщить об ошибке: https://github.com/fly4xy/Tiny-Tools/issues
- 📖 Документация: https://lis-carter.site/tiny-tools/docs

## Установка

Blender → **Edit → Preferences → Get Extensions** → **Install from Disk…** → выберите `tiny_tools-<версия>.zip`.
Панель: **3D Viewport → боковая панель (N) → Tiny Tools**.
