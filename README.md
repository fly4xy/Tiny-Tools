# Tiny Tools

**English** | [Русский](README.ru.md)

Blender add-on for rigging and animation (4.2 / 4.5 / 5.2 LTS): skeleton and animation backups, Pose Master (apply a pose as the new rest pose without breaking meshes and animations), animator key and pose tools, FBX animation export for Unreal Engine 5, vertex weight symmetrize, transfer and smooth.

- 🌐 Project page: https://lis-carter.site/tiny-tools/
- 🐞 Report a bug: https://github.com/fly4xy/Tiny-Tools/issues
- 📖 Documentation: https://lis-carter.site/tiny-tools/docs

## Install

Blender → **Edit → Preferences → Get Extensions** → **Install from Disk…** → choose `tiny_tools-<version>.zip`.
The panel is in **3D Viewport → Sidebar (N) → Tiny Tools**.
